# CRT Terminal 0.1.11

- Przejście po Enter trwa 7 sekund; czas animacji i zamknięcia nakładki
  pochodzi z jednej stałej.
- Smugi są dłuższe (55–100 vmax). Powtarzane przebiegi z różnymi fazami
  utrzymują ruch przez całą podróż, z łagodnym wejściem i wyjściem.
- Przy systemowym ograniczeniu ruchu pozostaje krótkie wygaszenie.
- Dynamika pasków panelu pozostaje propozycją do akceptacji.

Testów automatycznych ani odbioru wizualnego w natywnym oknie nie wykonano.
