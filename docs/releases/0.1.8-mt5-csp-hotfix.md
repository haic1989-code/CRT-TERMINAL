# CRT Terminal 0.1.8 — dostęp aplikacji do prywatnego portu mostu

Przyczyna błędu 0.1.7: most otrzymał prywatny port nadany przez Windows, ale
reguła `connect-src` w Tauri nadal dopuszczała wyłącznie localhost:8765.
Aplikacja nie mogła wysłać health checku mimo działającej usługi.

Poprawka dopuszcza porty na dokładnym adresie `http://127.0.0.1`, zachowując
kontrolę protokołu, instancji i właściciela. Reguła nie dopuszcza dowolnych
adresów sieciowych. Ekran startowy pokazuje także przyczynę nieudanego
sprawdzenia, obok ostatniego komunikatu przygotowania mostu.

Diagnostyka rzeczywistej sesji użytkownika: HTTP 200, protokół 2,
`terminal.connected=true`, `ok=true`. To potwierdza działanie mostu i
połączenie brokerskie w chwili odczytu. Pełny odbiór przepływu w natywnym
oknie po instalacji poprawki pozostaje do wykonania.
