# CRT Terminal 0.1.13 — poprawka widoczności tunelu

- Materiał smug renderuje obie strony. Geometria radialnych wstęg jest
  skierowana na zewnątrz, a kamera znajduje się wewnątrz tunelu;
  domyślne odrzucanie tylnych powierzchni usuwało smugi z obrazu.
- Stan gotowości GPU jest ustawiany po pierwszym renderowaniu bez błędu,
  zamiast natychmiast po utworzeniu renderera.
- Smugi CSS pozostają delikatną warstwą także przy aktywnym WebGL.
  Przy błędzie GPU wracają do pełnej jasności.
- Czas podróży pozostaje 7 sekund.

Testów automatycznych i odbioru wizualnego w natywnym oknie nie wykonano.
